# Shift Cipher Cryptanalysis

This directory contains the implementation of the Shift Cipher cryptanalysis using Brute Force, Dictionary Scoring, and Chi-Square Analysis.

## Directory Structure
- `src/`: Source code for the cipher and attacks
- `dictionary/`: Contains the dictionary file used for the dictionary attack
- `testcases/`: Test cases
- `outputs/`: Outputs of the programs
- `screenshots/`: Screenshots of the results
- `reports/`: Lab reports

## How to run
```bash
python3 src/main.py
```
